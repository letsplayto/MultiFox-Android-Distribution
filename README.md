# MultiFox-Android-Distribution

Official MultiFox Android distribution artifacts only. Source code remains private.

## Direct downloads

These stable links always point to the latest public release asset:

- **[Download the latest signed release APK](https://github.com/letsplayto/MultiFox-Android-Distribution/releases/latest/download/MultiFox-Android-release.apk)**
- [Download the latest debug APK](https://github.com/letsplayto/MultiFox-Android-Distribution/releases/latest/download/MultiFox-Android-debug.apk)
- [Download the latest SHA-256 checksums](https://github.com/letsplayto/MultiFox-Android-Distribution/releases/latest/download/SHA256SUMS.txt)

The signed APK link opens the APK asset directly. Android may show a download or installation confirmation depending on device and browser settings.

See [RELEASE-HISTORY.md](RELEASE-HISTORY.md) for every public Android release, release notes, direct version-specific links, and an explanation of unpublished version gaps.
