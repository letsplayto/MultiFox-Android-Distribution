## Release-history disclaimer

The public channel intentionally contains only distributable, signed Android releases. A version gap can therefore occur when a build was a private development build, a debug-only build, a signing or verification test, a failed workflow, or an internal build that was never suitable for public distribution. Version gaps do not imply that an APK was silently removed or that the public source repository was exposed. Each listed release is the authoritative public record for its published APKs and notes.

## MultiFox Android 0.4.4 — Public Beta

Official Android distribution artifacts. The MultiFox source repository and build workflow remain private.

This release updates the in-app updater to use this public distribution feed, so private source releases can still be delivered securely as public signed APK updates.

- `MultiFox-Android-release.apk` — signed public APK.
- `MultiFox-Android-debug.apk` — debug-signed development APK.
- `SHA256SUMS.txt` — checksums used by the in-app updater.
